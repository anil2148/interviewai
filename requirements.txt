# =============================================================================
#  NOTES FOR WEB SERVICE DEPLOYMENT
# =============================================================================
#
#  1. Ollama must be running separately:
#       ollama serve
#       ollama pull phi3:mini   # or whichever model is configured
#
#  2. Start the web service:
#       uvicorn new_1:app --host 0.0.0.0 --port 7788 --reload
#
#  3. REST API endpoints (built-in http.server, always available):
#       POST  http://localhost:7788/ask          {"prompt": "your question"}
#       GET   http://localhost:7788/status       health check
#
#  4. For production, add a reverse proxy (nginx / caddy) in front of uvicorn.
#
#  5. GPU acceleration for faster-whisper (optional):
#       pip install faster-whisper  # already above
#       pip install nvidia-cublas-cu12 nvidia-cudnn-cu12  # CUDA 12.x
#       Then set compute_type="float16" and device="cuda" in settings.
#
#  6. Docker one-liner:
#       docker run --rm -p 7788:7788 \
#         -v ~/.ai_assistant:/root/.ai_assistant \
#         python:3.12-slim \
#         sh -c "pip install -r requirements.txt && uvicorn new_1:app --host 0.0.0.0 --port 7788"
# =============================================================================
